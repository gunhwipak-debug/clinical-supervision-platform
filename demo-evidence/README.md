# ClinicFlow Demo Evidence

This directory stores screenshots, generated handoff packets, smoke reports, and audit outputs.

Only the Origin-14 rebuild evidence under `demo-evidence/rebuild-tech-ui/` is part of the current UI/UX source-of-truth chain, and even there the approved 14 PNG screenshots are the visual baseline.

Historical generated files such as `DESIGN-HANDOFF.md`, `DESIGN-HANDOFF.json`, `STITCH-PROMPTS.md`, and `STITCH-PROMPTS.json` are retained for provenance and tooling compatibility. They are not current implementation instructions.

If a file in this directory conflicts with:

- `AGENTS.md`
- `docs/ui-ux/clinicflow-origin14-design-system.md`
- `docs/ui-ux/clinicflow-current-design-contract.md`

the active documents above win.
