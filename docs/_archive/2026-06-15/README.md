# ClinicFlow Historical Archive

This folder contains historical reference documents from earlier ClinicFlow planning, prompt, design handoff, audit, and deployment phases.

These documents are not current implementation instructions.

Codex and future agents must not use this folder as an active source of truth. If an archived document conflicts with active documentation, the active documentation wins.

Current active standards live in:

- `AGENTS.md`
- `docs/ui-ux/clinicflow-origin14-design-system.md`
- `docs/ui-ux/clinicflow-current-design-contract.md`
- `docs/ui-ux/clinicflow-route-alignment-manifest.md`
- `docs/ui-ux/clinicflow-ia-navigation-refactor-plan.md`
- `docs/architecture/clinicflow-route-auth-status-contract.md`
- `docs/release/clinicflow-deployment-contract.md`

Archive categories:

- `old-prompts/`: old MVP or generation prompts.
- `old-design-handoff/`: superseded design handoff packets.
- `old-audits/`: older audit reports that may no longer describe the current route surface.
- `legacy-deployment/`: deployment guides that are no longer the current target.
- `historical-evidence/`: supporting evidence preserved for traceability only.
