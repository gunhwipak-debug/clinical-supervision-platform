# ClinicFlow Posteady Structural Reference

Posteady is a structural reference only. It is not a visual style source for ClinicFlow.

ClinicFlow keeps the Origin-14 baseline visual language: Noto Sans KR, deep slate text, electric-blue action details, thin borders, restrained panels, and desktop-first workflow clarity. Do not copy Posteady colors, brand, tone, assets, rounded style, or casual SaaS language.

Origin-14 is the baseline, not the ceiling. It prevents regression into generic AI card UI, but it must not block clearer desktop workbench layouts.

## Borrowed Patterns

- Clear public product preview: the homepage should show what the actual app does, not generic feature cards.
- Fixed desktop sidebar: authenticated work should feel like a stable workspace with role-aware navigation.
- Grouped navigation: sidebar groups should explain the role's work areas without overloading the top header.
- Top utility bar: authenticated top bars are for account and utility actions, not duplicated workflow navigation.
- Workbench main area: use board, list, table, or wizard structure according to the route's task.
- One primary action per item: each row/card should make the next action obvious.
- Structure over explanation: the layout should explain the workflow before helper copy does.

## Forbidden Interpretations

- Do not copy Posteady's visual style, brand, colors, copy, illustrations, or assets.
- Do not introduce casual social-media SaaS tone.
- Do not turn every route into a kanban board.
- Do not reintroduce noisy cards, decorative metric blocks, generic helper panels, or large explanatory banners.
- Do not create a parallel shell or navigation system.

## ClinicFlow Application

Public pages may use app-like previews and segmented demonstrations when they clarify the service flow. Authenticated pages should preserve the existing AppShell, sidebar, account menu, and admin shell, then improve page-level workbench structure inside them.

Origin-14 remains the visual baseline. This document only clarifies a desktop information-architecture reference.
